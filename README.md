# Справочник АЭ — веб-версия для iPhone

Тот же каталог, что в Android-приложении. Без App Store и без оплаты Apple.

## Как открыть на iPhone

1. Откройте в **Safari**: https://freon717.github.io/ae69-catalog-web/
2. Нажмите **Поделиться** (квадрат со стрелкой).
3. Выберите **На экран «Домой»**.
4. На рабочем столе появится иконка **Справочник АЭ**.

После первого запуска с интернетом справочник работает офлайн: поиск, карточки, состав, «входит в состав», избранное, недавние.

Фотографии подгружаются с ae69.ru, если есть сеть.

## Что обновляется само

Каталог тот же, что у Android: репозиторий `Freon717/ae69-catalog-data`.
Новая база подтягивается при наличии сети. Новый APK для этого не нужен.

## Что здесь нет

Admin, цены, склад, регистрации. Это только справочник сотрудника.
